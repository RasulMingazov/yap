# Documentation

Read the index for the area being changed.

The guides set the rules before the code exists. Where a guide names a module, tool, or helper that
the repository does not have yet, the first change that needs it adds it the way the guide says.
Until then the rule is a target, not a check that runs.

| Area | Use for |
| --- | --- |
| [Code conventions](001-code-conventions.md) | names, removing unused code, formatting, `when` branches, early returns, declaration ordering, and comments |
| [Server](server/README.md) | modules, use cases, routes, and persistence |
| [Shared contracts](shared/README.md) | DTO naming and the server/admin wire boundary |
